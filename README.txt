허니츄러스와 과메기단의 습격 — 첫 플레이 가능 버전

실행
- 웹: Play-Web.cmd를 더블클릭하면 로컬 서버와 브라우저를 엽니다. Node.js가 필요합니다.
- 현재 주소: http://127.0.0.1:8787
- 서버 없이: web/index.html을 브라우저로 열어도 됩니다. assets 폴더 위치를 유지하세요.
- Godot: project.godot을 Godot 4.7.1에서 열고 F6가 아닌 F5로 실행하세요.
- 배포용 웹: build/HoneyChurros-Web.zip. 압축을 풀고 index.html을 열거나 폴더를 정적 호스팅에 올립니다.

조작
Enter 선택 / 계속, 방향키 또는 WASD 이동 / 조준 / 앉기 (메뉴는 ←→로 값 변경)
Z 또는 J 사격 (붙어 있으면 나이프), X 또는 Space 점프 (↓+점프로 발판 아래로), C 또는 K 수류탄, Q 획득한 무기 교체
게임패드: A 점프, X 사격, B 수류탄, Y 교체, START 일시정지
위쪽 + 좌우: 대각선 조준. 공중에서 아래쪽 + 좌우: 아래 대각선 조준.
점프 키를 일찍 놓으면 낮게 점프합니다. 근접한 적에게 사격하면 추가 근접 피해를 줍니다.
Esc 또는 P 일시정지 메뉴, R 일시정지/컨티뉴에서 현재 미션 재도전, M 소리 켜기/끄기

구현
- 방송국, 벌집 공장, 해안기지, 해산물 요새의 4개 연결 스테이지.
- AKM, Kar98k, M4, RPG-26, FMG-9, Glock 19. 각기 다른 연사속도/탄약/위력/외형.
- 관통 소총, 범위 피해 로켓과 튕기는 수류탄, 탄약 소진 시 무한 탄약 권총으로 전환.
- 우리를 사격으로 파괴한 뒤 접근해 허니비 구출. 회복/무기/수류탄/점수 보상.
- 특수 허니비는 22초간 적을 향해 지원 사격.
- 보행/비행/중장갑/도약 적, 공격 예고와 적 탄환, 피격 무적, 체력과 목숨, 체크포인트.
- 공장 컨베이어, 끈적한 꿀, 바다와 움직이는 보트, 간헐적 증기 함정.
- 스테이지마다 3~4개 탐험 구역. 경비를 처치해 통로를 열고 모든 구역을 통과하면 보스 등장.
- 최종 초거대 과메기 전차. 병사 발사/탄막/꿀통 투척.
- 체력 절반 이하에서 장갑 손상과 본체 노출, 공격 가속. 처치 시 과메기들이 쏟아짐.
- 주인공 달리기 4프레임 및 대기/앉기/점프/피격 포즈, 방향에 맞춘 별도 무기 회전과 반동.
- 아이템 획득 시 실제 들고 있는 총과 탄환/발사광/반동/효과음 동시 변경. 검은 M4 적용.
- 좌우 반전과 앉기/점프의 손 위치를 공유해 총기 분리 수정.
- 과메기 8포즈와 몸체 변형, 보스 차체/궤도/포신/지휘관 독립 애니메이션 및 공격 예고.
- 메인 색 #FFD8D9의 둥근 HUD, 무기 카드, 구역 진행도, 보스 체력 표시.
- 배경 시차 스크롤, 꽃/먼지/피격 파편, 화면 흔들림, 합성 효과음/배경 리듬, 최고점 저장.

파일 구성
scripts/game.gd: Godot 고정 시간 간격 전투/진행 로직
scripts/presentation.gd: Godot 화면/애니메이션/UI
scripts/sound.gd: 외부 샘플을 쓰지 않는 합성 오디오
web/game.js: 브라우저 게임 로직 (레벨 데이터, 적/보스 AI, 진행 흐름)
web/audio.js: BGM 시퀀서, 합성 효과음, 아나운서 음성
web/render.js: Canvas 렌더링, 메뉴/HUD, 키보드·터치·게임패드 입력, 저장
web/fonts/: Black Han Sans, Jua (SIL OFL 1.1, 재배포 가능)
assets/: 사용자 제공 이미지 및 생성한 투명 애니메이션 시트/무기/배경
tools/test-game.cjs: 25개 게임 로직 검사 (node tools/test-game.cjs)
tools/test-touch.cjs: 터치 조작 검사
tools/test-render.cjs: 모든 웹 화면의 Canvas API 호출 검사 (실제 브라우저 시각 검사와 다름)
tools/package-web.cjs: 배포용 정적 웹 폴더 생성
docs/ART_PROMPTS.txt: 이미지 생성 방식과 프롬프트 기록

검증 및 한계
Godot 실제 실행과 제목/플레이/보스 화면 캡처를 확인했습니다.
브라우저 로직 16개 검사, 모든 화면 렌더 호출 검사 및 로컬 HTTP 200을 확인했습니다.
Godot에서 여섯 무기의 좌우 손 부착과 새로운 HUD/보스 조립 화면도 캡처해 확인했습니다.
이 환경에 연결된 브라우저 자동화가 없어 실제 브라우저에서의 키보드 플레이와 호환성은 미검증입니다.
Godot 웹 내보내기 템플릿이 없고 다운로드 네트워크가 제한되어, 웹 버전은 Canvas로 별도 구현했습니다.
export_presets.cfg는 향후 Godot WebAssembly 내보내기를 위한 단일 스레드 Web 프리셋입니다.
Godot 본체를 내보내려면 해당 엔진 버전의 내보내기 템플릿을 설치한 뒤 Web 프리셋으로 내보내세요.
Godot 소스와 웹 소스는 별도이므로 향후 규칙 변경은 양쪽에 반영해야 합니다.
현재는 전체 게임의 첫 플레이 가능 버전이며, 메탈슬러그 수준의 수작업 프레임 수/적 종류/레벨 연출을 완성한 상용 규모 결과물은 아닙니다.
모바일 조작, 게임패드, 전문 성우/음악, 세밀한 팔 관절별 조준 애니메이션, 정식 공개 배포는 포함하지 않습니다.
Godot용 korean.ttf는 현재 PC의 Malgun Gothic을 복사한 로컬 개발 폰트입니다. 공개 Godot 배포 전 재배포 가능한 한글 폰트로 교체하세요. 웹 ZIP은 이 폰트를 포함하지 않습니다.
