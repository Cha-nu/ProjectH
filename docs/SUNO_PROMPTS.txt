SUNO BGM 제작 가이드 (2026-10-21: 아래 프롬프트로 10곡 생성·적용 완료, 재생성 시 참고) — 허니츄러스와 과메기단의 습격

사용 방법
1. Suno에서 아래 프롬프트로 곡을 만들고 MP3로 다운로드합니다. (가사 없는 Instrumental 권장)
2. 파일 이름을 표의 "파일명"으로 바꿔 web/music/ 폴더에 넣습니다.
3. web/music/tracks.js에서 해당 줄의 // 를 지웁니다. 예: title:'title.mp3',
4. 파일이 없거나 재생에 실패한 트랙은 자동으로 기존 합성 음악이 나옵니다.
5. 배포 ZIP을 다시 만들려면: node tools/package-web.cjs

라이선스 주의
- 상업적으로 배포/판매할 게임이라면 Suno 유료 플랜(Pro/Premier)으로 "생성한" 곡을 쓰세요.
  무료 플랜에서 만든 곡은 비상업적 용도로만 쓸 수 있습니다. 최신 약관을 직접 확인하세요.

공통 스타일 (모든 프롬프트 뒤에 붙이면 통일감이 생깁니다)
  instrumental, retro arcade run-and-gun soundtrack, Metal Slug inspired, cute and upbeat, punchy drums, brass stabs, slap bass, no vocals
